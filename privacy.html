Dusk: Privacy Policy

Last updated 5 October 2026. Applies to the Dusk app for macOS and the "Dusk for Chrome" extension.

The short version

Dusk switches your Mac and your websites between light and dark. Appearance analysis happens on your computer. Dusk has no accounts, analytics, advertising, or automatic crash reporting. It stores the browser settings and remembered hostnames described below locally; it does not send them to Dusk. Appearance processing and optional Mac profile sharing happen locally. Configured release builds can contact their update feed to check for and download updates. You control automatic checks in Updates; manual checks also contact the feed. As with any download, its host receives normal connection data, including your IP address and request headers. Builds without valid updater configuration do not check.

What the Mac app reads

To tell you which apps will follow the switch, Dusk looks at:

  • The list of apps installed in your Applications folders, and each app's bundle information and program header, to see whether it was built with dark mode support.
  • Which apps are running, and which one is in front, to mark them in the list and to avoid reopening an app while you are using it.
  • Whether a microphone or camera is in use right now. This is a yes-or-no flag that macOS publishes. Dusk reads it so it never reopens an app in the middle of a dictation or a call. Dusk never opens the microphone or camera, cannot hear or see anything, and needs no permission for this.
  • One theme setting inside three other apps' own settings files, read-only:
    • Google Chrome: the appearance mode, and whether "Dusk for Chrome" is in its extension list.
    • Claude: the appearance choice.
    • Visual Studio Code: two appearance keys.
    • Any app you sync (see below): its one theme value.
    • Any app you chose to keep light (see below): the one appearance key Dusk wrote there, read back to check that it is set.
    • Apps listed in Recipes.json with a "read" entry (currently Logi Options+): the one or two keys that record its appearance choice. For Logi this is inside a database, which Dusk opens strictly read-only.

Those files contain other information that belongs to those apps. Dusk reads the files on your Mac, looks only for the keys named above, keeps nothing else, and never copies, stores or transmits their contents.

What the Mac app changes

  • The macOS appearance (light, dark, or automatic at sunset), which is the purpose of the app.
  • Visual Studio Code's settings file, only when you press a button asking for it. Dusk changes the appearance keys and keeps a backup copy of the original next to it.
  • One appearance setting in an app you choose to keep light. When you pick "Always light" for an app, Dusk writes a single standard macOS key (NSRequiresAquaSystemAppearance) into that app's preferences, and removes it when you choose "Follow Dusk" again. Dusk keeps a list of every app it did this to, so "Remove all" removes every one. It writes nothing else into other apps. On macOS 27, apps that keep their settings in protected storage (Apple's own apps such as Preview, and many App Store apps) need your permission first. See "Permissions" below.
  • The theme setting of an app you sync. A few apps have no "System" option of their own. When you press "Sync with Dusk" for one, Dusk changes that app's own theme value in its settings file (for example Wispr Flow's config.json), and again each time your Mac switches. It changes only that one value, keeps a backup of the original file next to it, and stops when you choose otherwise or press "Remove all". Which apps this applies to, and exactly which value, is listed in the app's Recipes.json.
  • Quitting and reopening an app, only with your permission. A few apps read their look only when they open. For each such app you choose whether Dusk may reopen it automatically, must ask you each time, or never may. Dusk always quits an app the polite way, so the app can still ask you to save, and gives up if it does not quit. It never does this while a microphone or camera is in use.
  • Its own preferences (your schedule, trigger choice, per-app choices, reopen permissions and skipped setup items), stored by macOS in your user account.
  • Saved appearance profiles in ~/Library/Application Support/Dusk/profiles.json. Profiles contain names, appearance/schedule choices, app identifiers and website hostname rules. They stay on your Mac.
  • An optional Chrome native-host registration at ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.dusk.profiles.json, created only when you press Connect Mac. The read-only helper returns the active profile's browser settings to Dusk's authorized extension. It does not accept commands to change apps or read arbitrary files.
  • A copy of the Chrome extension in ~/Library/Application Support/Dusk/, when you ask to install it.

Permissions

Dusk does not request Screen Recording, Accessibility, Input Monitoring, Camera, Microphone, Contacts or Location. It uses the following only if you turn them on:

  • Files & Folders, one app at a time (macOS 27). macOS protects the settings of apps such as Preview, so Dusk cannot change or read them on its own. macOS shows no prompt for this. When you choose "Always light" for such an app, Dusk tells you, and you turn that app on under Dusk in System Settings → Privacy & Security → Files & Folders. Dusk uses this permission only to write, read back and remove the one appearance key (NSRequiresAquaSystemAppearance) in the apps you chose. It reads nothing else there. The permission belongs to the official, signed copy of Dusk.
  • Files & Folders for Google Chrome, if macOS also blocks Dusk from reading Chrome's settings. Dusk uses it only for the Chrome items named in this policy.
  • Full Disk Access is optional and only a fallback. It also works, but it gives Dusk much more than it needs. With it, Dusk still reads and writes only what this policy lists.

You can turn any of these off at any time in System Settings → Privacy & Security. Without the permission, Dusk cannot change, check or remove the key in those apps until you turn it back on.

What the Chrome extension does

  • It runs on the websites you visit so it can darken the ones that have no dark mode. To decide, it inspects the page's visual properties: background and text colours, text length, image pixels, and SVG paint colours. It may inspect image and SVG data already used by the page. It does not collect or store page text, forms, passwords or cookies, and does not send those to Dusk or an analytics service.
  • To classify an image that the browser will not let it inspect directly, the extension may request that image's existing URL again from its host. It omits cookies and the referrer and asks Chrome to use its cache, but a network request can still occur. The image host may receive normal connection data such as your IP address, the requested URL and request headers. Pixel and SVG colour analysis stays local.
  • It stores, only in your browser: your chosen mode, your per-site choices (always dark, always light, or off), and two lists of up to 300 hostname/appearance entries each with whether a page was light or dark, which can speed up decisions on repeat visits. Oldest entries are dropped automatically, and the popup's "Forget remembered sites" button clears both lists at any time.
  • Private (incognito) windows: Chrome keeps extensions out of them unless you allow it. If you allow it, automatic detection does not remember those visits. Settings you explicitly save in the popup are browser preferences and may persist after a private window closes.
  • Optional Mac profiles: after you connect, the extension reads a local profile snapshot roughly every 30 seconds. It stores that snapshot and any local override rules in browser storage. The helper receives only a fixed request for the active profile, not your current URL or page content.
  • Problem reports are previewed locally and copied only when you press Copy. A hostname is optional. No full URL, page text, screenshot or query string is included, and nothing is submitted automatically.
  • Permissions in the Chrome Web Store build: storage for settings, activeTab for the popup's current website and status, and scripting to apply the same bundled page scripts to tabs that were already open when Dusk is installed or updated (on the same websites those scripts already run on). A build that includes the optional local Mac connection additionally declares nativeMessaging (to talk to the Dusk app on this computer) and alarms (to refresh that connection). It loads no remote code. The image requests described above can still occur.

Chrome Web Store Limited Use

The Chrome extension uses the website information and local settings described above only to provide its appearance features. Its use of this information follows the Chrome Web Store User Data Policy, including the Limited Use requirements. Dusk does not sell this information or use it for advertising, creditworthiness or lending. The developer does not receive or read your page content or remembered sites. Image requests go only to the existing image host as described above, to provide the appearance feature; Dusk does not send that information to an analytics or advertising service.

Removing your data

  • Mac app: delete ~/Library/Application Support/Dusk/ and run defaults delete dev.calvin.dusk. Press "Remove all" under Exceptions first, so any app you kept light goes back to normal. Keep any Files & Folders permission on until that finishes, then turn Dusk off in System Settings → Privacy & Security → Files & Folders (and Full Disk Access, if you used it). Restore any *.dusk-backup file if you want an app's original settings back.
  • Remove the optional native-host registration by deleting ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.dusk.profiles.json.
  • Extension: removing it from Chrome deletes its stored profiles, settings and remembered appearances.

Children

Dusk has no accounts or child-specific features. It does not send locally stored browser settings or remembered hostnames to Dusk.
