Dusk for Mac: App Store Support

For the Dusk edition downloaded from the Mac App Store. Updated 10 November 2026.

What this edition does

Dusk switches your Mac between Light and Dark appearance. You can choose a mode yourself or set a daily schedule. This App Store edition controls macOS appearance only. It does not install the Dusk for Chrome extension or the separate direct-download edition.

Requirements

This edition requires macOS 14 or later and Apple’s Shortcuts app.

Set up Light and Dark

Open Dusk’s Settings and choose Setup guide. The guide opens Shortcuts or the relevant shortcut editor and explains what to click. Basic setup is selected first: create two shortcuts with Apple’s Set Appearance action, one fixed to Light and one to Dark. Choose fixed appearances, not Toggle. Save two distinct, exact shortcut names in Dusk.

Compatibility is optional. It offers prepared Light and Dark shortcuts, or manual creation under Shortcut setup → Troubleshoot → Set a shortcut up by hand. Inspect each shortcut before adding it. If Shortcuts finds an existing name, choose deliberately: Keep Both preserves the original and gives the copy its own name. Save the actual name shown in Shortcuts. Do not replace a working shortcut unless you intend to replace it. Both Compatibility routes require Allow Running Scripts (a setting for Shortcuts generally). macOS may also ask you to allow Shortcuts to control System Events; you decide whether to grant that permission. Basic setup remains available without the supplied scripts.

Before Dusk tests a new, unverified shortcut, open it from Prepare new shortcuts and press Run in Apple Shortcuts. Review any prompt yourself. Wait until Stop returns to Run, with no error or pending prompt, and check that the Mac reached the requested appearance. Return to Dusk and confirm that the run finished. This is preparation only: choose Test Light & Dark so Dusk can check both appearance changes and successful Shortcuts replies. Setup complete appears only after Dusk has verified both shortcuts.

If you edit a name but have not saved it, save the exact name or restore the saved name before confirming preparation. If you open a prepared import that could replace a verified shortcut, Dusk will require a fresh check even if you later cancel the import. This protects against relying on a test of an older shortcut. Dusk cannot see edits or imports made independently in your Shortcuts library; after changing a shortcut outside Dusk, retest it before using Auto.

Dusk opens the shortcuts you name. It cannot inspect or cancel their actions. Shortcuts is a separate Apple app and may show its own interface or messages.

If a test takes too long

A timeout does not cancel the shortcut in Apple Shortcuts. Do not keep pressing Run or Test. Inspect the pending shortcut, finish any prompt, or stop the run. Acknowledge recovery in Dusk only after checking that no run remains pending. New shortcuts may take longer on their first run; Dusk does not promise that a delay happens only once or ends within a particular time. If the run fails, keep the actual error for your own troubleshooting and describe it without sharing private content.

Using Auto and other apps

After both shortcuts are verified, set distinct Dark and Light hours and enable Auto. Dusk must be running and your Mac available for scheduled changes. After sleep, Dusk checks the current schedule when it can resume. A manual Light or Dark choice pauses Auto. Another app must support system appearance and be configured to follow it; Dusk does not override that app’s theme setting or recolor websites. Use a fixed macOS appearance setting (System Settings → Appearance) to avoid a competing system Auto schedule. Other appearance utilities can also change the mode independently.

Turn on Open at login if you want Dusk to start when you sign in. If macOS asks, approve Dusk in System Settings → General → Login Items.

Scheduled changes use a Shortcuts URL and observe the requested appearance. This observation does not confirm that a shortcut finished or caused the change. If a change cannot be confirmed, Auto pauses and will not retry automatically.

Report a problem

Choose Report a problem in Dusk’s Settings. Describe what you expected and what happened, then review the preview. The included status lines are Dusk/build and macOS versions, current appearance, Auto status, recovery status, setup stage and verification state. Shortcut names or contents, screenshots, logs and browsing history are not attached automatically. Avoid putting private information in your description. Copy report copies what you see; Open email draft opens a draft to duskformac@gmail.com that you review and send yourself. Nothing is sent automatically.

Privacy and removing settings

Open Privacy & Help in Dusk, then Privacy policy, for local-settings removal instructions and how to request deletion of a report you emailed. Emailing support is optional. Resolved reports are deleted from our support mailbox within 90 days; earlier deletion can be requested at the support address.

Contact support

Email duskformac@gmail.com. Tell us what happened and which macOS version you use. Email is voluntary: if you contact us, we receive your email address, any sender name included by your email app, and the information you include so we can reply. Please do not send passwords or other sensitive information.
