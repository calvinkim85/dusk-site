Dusk for Mac: App Store Support

For the Dusk edition downloaded from the Mac App Store. Updated 23 September 2026.

What this edition does

Dusk switches your Mac between Light and Dark appearance. You can choose a mode yourself or set a daily schedule. This App Store edition controls macOS appearance only. It does not install the Dusk for Chrome extension or the separate direct-download edition.

Scheduling and manual mode

Dusk's daily schedule runs while Dusk is open and your Mac is awake. If you choose Light or Dark manually, Dusk pauses the schedule so it does not immediately change your choice back. Choose the schedule again to resume automatic switching. If the Mac is asleep at a scheduled time, Dusk applies the current scheduled mode after it wakes, while Dusk is running.

For scheduled switching after you sign in, turn on Open at login in Dusk. This is optional. Dusk does not run while you are signed out.

macOS Automatic appearance

macOS also has its own Automatic appearance setting. If it is enabled, macOS may change appearance on its own and conflict with Dusk. For Dusk to control the schedule, set macOS Appearance to Light or Dark instead of Auto in System Settings.

Allowing Dusk to switch appearance

Dusk may ask permission to control appearance through System Events. Allow it when macOS presents the Automation prompt. If you denied it or need to change the choice later, open System Settings → Privacy & Security → Automation, find Dusk, and enable System Events. Then quit and reopen Dusk. Dusk uses this permission only to read and change the system appearance.

Dusk requires macOS 14 or later.
